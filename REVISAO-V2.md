# FORTIS SSMA — V2

## O que mudou
- Reposicionamento do hero para falar diretamente com empresas e operações.
- Texto institucional atualizado com o briefing recebido.
- Catálogo reorganizado com as especialidades descritas pela FORTIS.
- Seção de treinamentos com NR-01, NR-06, NR-10, NR-11, NR-12, NR-20, NR-23, NR-33 e NR-35.
- Inclusão de LOTO, brigada, primeiros socorros, uso de extintores e treinamentos personalizados.
- Blocos de experiência técnica, segmentos atendidos e processo de orçamento.
- FAQ revisado e formulário ampliado com cidade, segmento e número de colaboradores.
- Metadados básicos de SEO atualizados.
- Ajustes responsivos para as novas seções.

## Pendências antes da publicação
1. Confirmar razão social e CNPJ conforme cadastro oficial antes de publicar dados legais.
2. Confirmar responsáveis técnicos, qualificações, registros, certificados, escopo de laudos e medições.
3. Confirmar autorização para publicar fotos, cases, marcas e pessoas identificáveis.
4. NR-18 não foi incluída no catálogo, pois consta como pendente de confirmação no briefing.

## Como executar localmente
Requer Node.js compatível com Vite 6.

```bash
npm install
npm run dev
```

Para gerar a versão de produção:

```bash
npm run build
npm run preview
```

## Observação de validação
A instalação das dependências e a compilação de produção não puderam ser concluídas neste ambiente, pois o acesso ao registry npm expirou durante a tentativa de instalação. O projeto foi atualizado em código-fonte, mas precisa passar por `npm install` e `npm run build` em um ambiente com acesso ao npm antes de homologação.
