# FORTIS SSMA — protótipo de landing page

Protótipo navegável em React + Vite + Tailwind CSS, com direção visual BOLD (verde, preto e branco), responsividade e interações.

## Rodar localmente

```bash
npm install
npm run dev
```

Para validar a versão de produção:

```bash
npm run build
npm run preview
```

## Publicar no Netlify

- Build command: `npm run build`
- Publish directory: `dist`
- Node: versão LTS atual

## Antes de publicar para o cliente

Este é um protótipo visual. Revisar e confirmar:
- telefone e link de WhatsApp;
- e-mail e endereço, caso sejam incluídos;
- região efetivamente atendida;
- escopo exato dos serviços e treinamentos;
- habilitações e responsáveis técnicos;
- qualquer número, certificação, depoimento ou alegação de resultado.

Não foram adicionados números de clientes, anos de experiência, certificações ou resultados não confirmados. Os itens marcados com asterisco no bloco de soluções precisam de validação do cliente.

## Imagens

As imagens são referências externas do Unsplash para prototipagem. Substituir por imagens licenciadas/aprovadas e otimizar antes da publicação definitiva.
